next-show-radar

The geolocation-aware tour map from The DJ Calendar. Allow the location prompt to see the nearby fit; decline it to see the deny contract - a full global view and a calm, announced fallback. Either answer gets a working map.

Default - 200 mile radius, CARTO dark tiles

Re-run after a permission change? then reload - it clears the cache and the denial memory via NextShowRadar.reset().

Knobs - 60 mile radius, custom color, lower fallback zoom
